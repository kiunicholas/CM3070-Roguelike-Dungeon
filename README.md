\# CM3070 Roguelike Dungeon Generation Project



This repository contains the Unity prototype for my CM3070 Computer Science Final Project.



\## Project Overview



The project is a 2D roguelike dungeon exploration prototype developed in Unity using C#. It focuses on procedural dungeon generation, where rooms, connections, enemies, loot, and exits are generated at runtime.



\## Main Features



\- Procedural room-based dungeon generation

\- Graph-based room connections

\- BFS reachability validation

\- Unity Tilemap rendering

\- Player movement and wall collision

\- Enemy and loot placement

\- Player health system

\- Dungeon regeneration

\- Batch evaluation logging



\## Controls



\- WASD / Arrow Keys: Move

\- R: Regenerate dungeon

\- T: Run batch evaluation
